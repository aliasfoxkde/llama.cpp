POST /completion Generate text completion ▶

Request Body

FieldTypeDefaultDescription
promptstring—Input text (required)
n_predictint128Max tokens to generate
temperaturefloat1.0Sampling temperature (0.0–2.0)
top_pfloat0.95Nucleus sampling threshold
top_kint20Top-k sampling
stoparray[]Stop sequences, e.g. ["</s>"]
cache_type_kstringq4_0KV cache K type (per-request override)
cache_type_vstringq4_0KV cache V type (per-request override)
seedintrandomRandom seed for reproducibility

Supported KV Cache Types

f16, q4_0, q4_1, q5_0, q5_1, q8_0, iq4_nl, f32, bf16

Note: K != V makes zero measurable difference. Use symmetric q4_0/q4_0.

Response Fields (OpenAI-compatible)

{
  "id": "cmpl-abc123",           // Unique completion ID
  "object": "text_completion",   // Always "text_completion"
  "created": 1234567890,        // Unix timestamp
  "model": "Qwen3.8-27B",       // Model name
  "system_fingerprint": "...",   // Backend fingerprint
  "choices": [{
    "text": "...",               // Generated text
    "index": 0,                  // Always 0 for streaming
    "logprobs": null,            // Always null
    "finish_reason": "stop"      // "stop", "length", or "content_filter"
  }],
  "usage": {
    "prompt_tokens": 12,         // Tokens in prompt
    "completion_tokens": 128,    // Tokens generated
    "total_tokens": 140          // Sum of above
  }
}

Agent/Orchestration Examples

Python

import requests, time

API = "http://localhost:8082"

def wait_ready(timeout=30):
    """Poll health until ready."""
    start = time.time()
    while time.time() - start < timeout:
        try:
            if requests.get(f"{API}/health").status_code == 200:
                return True
        except: pass
        time.sleep(0.5)
    return False

def complete(prompt, n_predict=128, **kwargs):
    """Send completion request."""
    payload = {"prompt": prompt, "n_predict": n_predict, **kwargs}
    resp = requests.post(f"{API}/completion", json=payload)
    resp.raise_for_status()
    return resp.json()

# Usage
if wait_ready():
    result = complete("Explain recursion", temperature=0.7)
    print(result["content"])

JavaScript/Node

const API = "http://localhost:8082";

async function waitReady(timeout = 30000) {
  const start = Date.now();
  while (Date.now() - start < timeout) {
    try {
      const res = await fetch(`${API}/health`);
      if (res.ok) return true;
    } catch {}
    await new Promise(r => setTimeout(r, 500));
  }
  return false;
}

async function complete(prompt, options = {}) {
  const resp = await fetch(`${API}/completion`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ prompt, n_predict: 128, ...options })
  });
  return resp.json();
}

// Usage
if (await waitReady()) {
  const result = await complete("Tell me a joke");
  console.log(result.content);
}

Timing & Polling

Model Load Times

Ultra (IQ3_XXS):  ~2.3 seconds
Turbo (REAP-MTP):   ~9.6 seconds

Service stop:        ~2 seconds
Total switch time:   ~4-12 seconds

Health Polling Pattern

# Wait for server to be ready (max 30s)
timeout 30 bash -c 'until curl -s http://localhost:8082/health | grep -q "ok"; do sleep 0.5; done'
echo "Server ready"

Switch + Wait Pattern

curl -X POST http://localhost:8082/model -d '{"model": "Turbo"}'
# Proxy switches model (~2s stop + ~9.6s load)
timeout 60 bash -c 'until curl -s http://localhost:8082/health | grep -q "ok"; do sleep 0.5; done'
echo "Turbo model ready"
